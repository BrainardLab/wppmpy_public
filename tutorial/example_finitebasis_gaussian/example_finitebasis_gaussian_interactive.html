Bayesian function estimation with a finite sinusoidal basis

Interactive companion to the example_finitebasis_gaussian notebook in wppmpy_public. A function on [0, 2π) is represented as a weighted sum of sinusoids; a Gaussian prior on the weights (standard deviation decaying with frequency, σj = γ·e−ε·kj) encodes smoothness; noisy measurements yield a closed-form Gaussian posterior. Move the sliders — every panel recomputes live. All computation runs in this page; no server or Python needed.

 

1 · Basis functions

About

Each candidate function is f(x) = w₀ + Σₖ [w cos(kx) + w sin(kx)]. The traces are the N basis functions, offset vertically — DC at the top, frequency increasing downward. Each cos/sin pair at the same frequency k shares a color (darker blue = higher frequency).

2 · The prior

About

Each weight has prior wj ~ N(0, σj²) with σj = γ·e−ε·kj: γ sets the overall scale, ε suppresses high frequencies — larger ε means smoother functions. Bars share the frequency color-coding of panel 1.

Data table

3 · Samples from the prior

About

Weight vectors drawn from the prior, each shown as its function f(x) = Bw — plausible functions before any data. Increase ε to make them smoother; decrease it to allow more wiggles.

Data table (sampled)

4 · Bayesian inference

About

A true function is drawn from the prior and measured at random locations with Gaussian noise. Because prior and likelihood are both Gaussian, the posterior over weights is Gaussian in closed form; its mean function is the best estimate given the data.

Measurements table

5 · More data → better estimate

About

The same true function with more measurements: each measurement adds a row to the design matrix, pulling the posterior mean toward the data and shrinking its covariance.

6 · Credible intervals

About

The shaded band is the 95 % credible interval, mean ± 1.96·σpost(x), from the posterior predictive variance b(x)ᵀ Σpost b(x). The band is narrowest near measurements and widest in the gaps.

7 · Adaptive sampling

About

Instead of random placement, put each new measurement where the posterior is currently most uncertain (greedy maximum-variance design). Drag the step slider to watch the sequence; the dotted vertical line marks where the next measurement will land.

8 · Adaptive vs. random

About

Head-to-head with the same true function and noise: the same number of randomly placed vs. adaptively placed measurements. The same idea — placing trials where the current model is uncertain — underlies the AEPsych-driven data collection in Hong et al. (2025).
